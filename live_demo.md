## Quick usage
1. Open the link above (works on any phone browser, no install needed)
2. Go to the "Teacher Studio" tab to generate a lesson pack code
3. Go to "Student App" and paste that code (or click "Try Sample Lesson") to view it offline
4. Take the quiz to see the auto-generated reply cod
